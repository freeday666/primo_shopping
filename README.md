# ⚡ Wat is FreddoDev?

**FreddoDev** is een Windows 11 toolkit waarmee je verschillende
systeemcontroles en onderhoudstaken vanuit één workflow kunt uitvoeren.

Het project richt zich onder andere op:

- Windows Update
- Drivers
- Graphics
- Hardware
- Windows componenten
- Systeembestanden
- HID/I2C-apparaten
- Performance troubleshooting
- Debug logging
- Algemene Windows 11 troubleshooting

---

# ✨ Features

| Feature | Beschrijving |
|---|---|
| ⚡ Full Fix | Gecombineerde Windows-controles en reparaties |
| 🔄 Windows Update | Beschikbare Windows-updates controleren |
| ⚙️ Drivers | PnP-apparaten en driverstatus controleren |
| 🎮 Graphics | Display-adapters controleren |
| ⌨️ HID / I2C | Input- en hardwareapparaten controleren |
| 🛠️ DISM | Windows component store controleren/repareren |
| 🔍 SFC | Windows systeembestanden controleren |
| 📦 App Updates | Beschikbare package/app updates controleren |
| 🐛 Debug Mode | Uitgevoerde acties en fouten loggen |
| ♻️ Restart | Windows opnieuw starten na onderhoud |

---

# 🪟 Windows 11

FreddoDev is primair ontworpen voor:

**Windows 11**

Sommige ingebouwde Windows-tools kunnen ook op andere
Windows-versies aanwezig zijn, maar de workflow van dit project
is gericht op Windows 11.
