⚠ Belangrijk

FreddoDev kan Windows Update, systeemreparaties, hardwaredetectie en beschikbare driverupdates gebruiken, maar kan niet garanderen dat iedere fabrikant altijd de nieuwste driver via Windows Update aanbiedt.

Voor laptop-specifieke drivers kunnen de officiële supportpagina's van de fabrikant nodig zijn.

Maak belangrijke bestanden altijd eerst beschikbaar via een back-up voordat je uitgebreide systeemreparaties uitvoert.
FAQ

Veelgestelde vragen.

Maakt FreddoDev mijn FPS onbeperkt?

Nee. FPS wordt uiteindelijk begrensd door onder andere GPU, CPU, game-engine, instellingen en de refresh rate van je monitor. FreddoDev kan wel helpen Windows- en driverproblemen te identificeren.

Verwijdert FreddoDev mijn persoonlijke bestanden?

De standaard reparatieacties zijn niet bedoeld om persoonlijke bestanden te verwijderen. Maak wel altijd een back-up voordat je systeemonderhoud uitvoert.

Kan FreddoDev iedere driver automatisch installeren?

Niet iedere fabrikantdriver wordt via Windows Update aangeboden. Voor sommige systemen zijn OEM- of fabrikantdrivers noodzakelijk.

Wat doet Debug Mode?

Debug Mode registreert de uitgevoerde stappen en fouten in een logbestand zodat problemen achteraf onderzocht kunnen worden.

Werkt FreddoDev op Windows 10?

FreddoDev is primair ontworpen voor Windows 11. Sommige onderliggende Windows-tools bestaan ook op Windows 10, maar de volledige workflow is gericht op Windows 11.

Waar kan ik hulp krijgen?

Je kunt deelnemen aan de FreddoDev Discord community voor support, feedback, releases en algemene hulp.
